# 📲 جنرالز اندروید — راهنمای نصب

نسخه‌ی فارسیِ بومی Command & Conquer: Generals برای اندروید — غیررسمی و اجتماعی، بدون وابستگی به EA.

---

## ۱) دانلود اپ

فایل اپ **همین‌جا داخل همین مخزن** قرار دارد:

👉 **[دانلود GeneralsAndroid-v0.1.2-alpha-release.apk](https://github.com/obsifox/GeneralsAndroid/raw/main/GeneralsAndroid-v0.1.2-alpha-release.apk)**

- حجم: حدود ۴ مگابایت — معماری arm64 (تمام گوشی‌های جدید)
- جمع کنترلی SHA256:
  `cad4e71f66998499c3da1d32e100f7e7001401b626881eb894a13316baae42b7`
- فایل `SHA256SUMS.txt` هم کنار همین فایل هست برای مقایسه.

## ۲) نصب

1. فایل APK را با گوشی دانلود کنید.
2. روی فایل بزنید؛ اگر پرسید، اجازه‌ی «نصب از منابع ناشناس» را بدهید.
3. دکمه‌ی «نصب» را بزنید و صبر کنید تا تمام شود.
4. اپ با نام «جنرالز اندروید» در منوی برنامه‌ها ظاهر می‌شود.

پیش‌نیاز: اندروید ۷ به بالا (ترجیحاً ۸ یا جدیدتر).

## ۳) اجرای اول — وارد کردن فایل‌های بازی

این اپ **فایل‌های بازی را همراه ندارد**؛ باید نسخه‌ی قانونی خودتان از Generals یا Zero Hour را وارد کنید:

1. در اجرای اول، ویزارد باز می‌شود → «انتخاب پوشه‌ی بازی» را بزنید.
2. پوشه‌ی فایل‌های بازی خودتان را روی حافظه‌ی گوشی انتخاب کنید.
3. اپ فایل‌ها را بررسی و نتیجه را به فارسی نشان می‌دهد (اگر چیزی کم بود، می‌گوید چه).

## ۴) بازی شبکه‌ای با هات‌اسپات

بدون اینترنت، فقط با هات‌اسپات:

1. یک نفر (میزبان) هات‌اسپات گوشی‌اش را روشن کند.
2. بقیه‌ی بازیکن‌ها به **همان هات‌اسپات** وصل شوند.
3. میزبان: «میزبان شدن بازی محلی» — بقیه: «پیوستن» و انتخاب میزبان از لیست.
4. در لابی: چت، آماده‌شدن، و شروع بازی.

## مشکلات رایج

- **نصب نشد؟** فایل ناقص دانلود شده — حجم و SHA256 را چک کنید و دوباره دانلود کنید.
- **در لابی همدیگر را نمی‌بینند؟** همه باید دقیقاً به یک هات‌اسپات مشترک وصل باشند (اینترنت لازم نیست، فقط اتصال وای‌فای مهم است). بعد دکمه‌ی «جست‌وجوی میزبان» را دوباره بزنید.
- سوال دیگر؟ بخش Issues در مخزن سورس.
